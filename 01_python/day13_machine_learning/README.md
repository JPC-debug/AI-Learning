## 一、机器学习基础概念

传统编程：

数据 + 规则 → 程序 → 结果

机器学习：

数据 → 算法 → 模型 → 预测结果


机器学习的目标：

让计算机通过已有数据学习规律，并利用规律预测新的数据。


核心概念：

### Feature（特征）

输入给模型的数据。

例如预测成绩：

- 学习时间
- 睡眠时间
- 刷题数量

通常用 X 表示。


### Label（标签）

希望模型预测的结果。

例如：

- 成绩
- 房价
- 分类结果

通常用 y 表示。


机器学习中：

X 表示输入数据

y 表示目标结果


## 二、机器学习数据结构

Scikit-learn 通常要求输入数据为二维结构：

```
样本数量 × 特征数量
```


例如：

```python
X = [
    [80,3,5],
    [120,4,8],
    [150,5,10]
]
```

表示：

- 有3个样本
- 每个样本包含3个特征


预测新的数据时：

```python
model.predict([[100,3,6]])
```

两个中括号表示：

- 外层：一个样本
- 内层：这个样本的特征


## 三、Scikit-learn 基础

Scikit-learn 是 Python 中常用的机器学习库。

基本流程：

```text
创建模型
↓
训练模型
↓
预测结果
↓
评价模型
```


创建模型：

```python
model = LinearRegression()
```


训练：

```python
model.fit(X,y)
```


预测：

```python
model.predict(X)
```


## 四、线性回归 Linear Regression

线性回归用于预测连续数值。

例如：

- 房价预测
- 成绩预测
- 销售额预测


线性回归寻找：

```
y = ax + b
```


其中：

- a：系数（coef_）
- b：截距（intercept_）


训练完成后：

```python
model.coef_

model.intercept_
```

可以查看模型学习到的参数。


## 五、fit() 学习过程

```python
model.fit(X,y)
```

表示：

使用已有数据，让模型寻找最合适的参数。


对于线性回归：

模型学习：

```
a是多少？
b是多少？
```


训练完成后：

模型得到：

```
输入数据 → 预测结果
```


## 六、模型评价

学习了两个评价指标：


### MSE（Mean Squared Error）

均方误差。

表示预测值和真实值之间的差异。

数值越小：

说明预测误差越小。


### R² Score

决定系数。

表示模型对数据规律的解释能力。

越接近1：

说明模型拟合效果越好。
